# Café Santa Prisca

A responsive restaurant page built with JavaScript modules and Webpack as part of The Odin Project curriculum.

## Preview

Add a screenshot here after deployment.

## Features

- Multi-page navigation without page reloads
- Modular JavaScript structure
- Dynamic menu rendering from data
- Responsive layout
- Custom styling and branding
- Menu cards with images
- Active navigation state

## Built With

- HTML
- CSS
- JavaScript
- Webpack

## What I Learned

- How to organize JavaScript code using ES modules
- How to bundle assets with Webpack
- How to dynamically render DOM elements
- How to separate data from UI logic
- How to improve a basic project into a more polished user experience
